# Audio-Amplifier

1.Project Overview

This project involves designing and building a portable audio amplifier using the LM386 audio amplifier IC. The circuit amplifies low-level audio signals and delivers the amplified output to a speaker.

The amplifier includes adjustable volume, gain control, and a bass boost feature to improve the audio listening experience.


2.Hardware Components

10Kohm Resistor

1000µF Capacitor

0.1µF Capacitor

100µF Capacitor

470pF Capacitor

Audio Jack

Speaker 

240v to 12v Step-down Transformer


3.Working Principle

The circuit operates by receiving an audio signal through the audio input jack, which is then regulated using a 10K potentiometer to control the input volume. 
The LM386 audio amplifier IC amplifies the signal, while another 10K potentiometer allows adjustment of the amplifier gain. A separate bass boost control circuit 
is used to adjust the bass response and enhance the low-frequency audio output. Finally, the amplified audio signal passes through a 1000µF output capacitor 
before being delivered to the speaker, producing the amplified sound.
